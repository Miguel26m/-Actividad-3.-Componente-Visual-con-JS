# 🎠 Librería de Componentes UI: Carrusel Dinámico

## 🎯 Portada: ¿Qué problema resuelve?
**Nombre del componente:** Carrusel Interactivo Dinámico (Vanilla JS).

**Problema que resuelve:** En el desarrollo web moderno, mostrar mucha información (imágenes, títulos y descripciones) puede saturar la pantalla. Este componente resuelve el problema del espacio proporcionando una interfaz limpia y navegable. Al ser **100% dinámico y reutilizable**, evita que el desarrollador tenga que escribir código "hardcodeado" o depender de librerías externas o frameworks. Permite instanciar múltiples carruseles en una misma página de forma completamente independiente.

---
